# Instagram Analysis Dashboard

A Power BI-based dashboard project for analyzing Instagram performance, audience engagement, and content growth insights.

This repository contains the project metadata for a Power BI report named `instegramAnalysis`, along with the dashboard documentation needed to understand the purpose, scope, and setup of the analysis.

## Project Purpose

The Instagram Analysis Dashboard is designed to help brands, creators, and marketers monitor key performance indicators (KPIs) related to Instagram accounts. It brings together critical metrics such as:

- follower growth
- engagement rate
- reach and impressions
- post performance
- content trends
- audience behavior and demographics
- campaign and content effectiveness

The goal is to turn raw social media data into clear, actionable insights that support better content planning and business decisions.

## Report Artifact

The project is configured as a Power BI Project (`.pbip`) and references a report artifact stored in:

- `instegramAnalysis.Report`

The project metadata is defined in:

- `instegramAnalysis.pbip`

## Dashboard Focus Areas

This dashboard can be used to evaluate:

- which posts generate the most engagement
- when the audience is most active
- which content themes are driving results
- how follower growth changes over time
- how content performs by format or campaign
- what audience segments are most engaged

## Typical Metrics Included

Depending on the dataset used, the report may include metrics such as:

- total followers

- post reach
- impressions
- likes, comments, and shares
- engagement rate
- follower growth rate
- best-performing posts
- audience geography and engagement patterns

## Power BI Project Structure

This project follows the Fabric/Power BI project structure:

```text
Instagram-Analysis-Dashboard/
├── instegramAnalysis.pbip
├── instegramAnalysis.Report/
├── README.md
└── ...
```

The `.pbip` file is the project descriptor used by Power BI/Fabric to identify the report and project settings.

## How to Open the Project

To work with this project in Power BI:

1. Open Power BI Desktop or Fabric Power BI project tooling.
2. Load the `instegramAnalysis.pbip` project file.
3. Open the report artifact in the `instegramAnalysis.Report` folder.
4. Refresh the dataset or connect to your Instagram data source.
